KEYFORGE / PROJECT NOTICE

Practice, with clear boundaries.

KeyForge is an independent personal fork of Keybr with a new developer typing lab. It is not operated by or affiliated with the Keybr service.

Local typing data

Ordinary guest typing data and Code Lab data are stored in your browser, in separate stores. Code Lab keeps up to 200 session summaries, including character and pair statistics. Clearing site storage removes that data. Use Code Lab JSON backups to move its history between devices.

Your code

Custom Code Lab snippets remain in the current tab. They are displayed as text, never executed, and not included in saved session summaries. Character patterns are retained in statistics. Do not practice passwords, credentials, confidential source, or other secrets.

Server features

The native racing service uses server connections and session cookies. If the operator enables accounts, ordinary account profiles and typing results are stored on this installation's server. Authentication providers receive the information needed for sign-in. Code Lab does not currently synchronize through those accounts.

Tracking

The fork's page shell removes upstream advertising and analytics injection. Hosting infrastructure can still receive normal requests and keep operational access logs. This project does not claim to make you anonymous to its hosting provider.

Use and availability

This is experimental software for practice, not a standardized assessment or a guarantee of skill. Back up your data. Availability and preservation of data are not guaranteed.
